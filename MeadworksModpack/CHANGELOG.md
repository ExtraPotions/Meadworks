# Changelog

## 0.1.4 (2026-10-20)

- Dependency pins refreshed to the October 20 follow-up release: Crucible 0.3.24 (Crucible.UI 0.3.17), Burrow 0.3.20, Cairn 0.1.14, Edge 0.2.10, Inscribe 0.2.2, Kindle 0.1.20, Mantle 0.1.22, Threshold 0.3.9, Wildblood 0.5.2 and Wildroot 0.1.14.
- Windows installer redesigned: one window in the suite's Timber look with Mods, What's new and Backups tabs; mods can be switched on or off before installing (disabled mods are installed disabled, as r2modman does); each row shows its backup, install and verification progress; a backup can be restored or deleted from the Backups tab.
