# Source availability and attribution

Product author: expDARE. The Corresponding Source for this version is at https://github.com/ExtraPotions/Meadworks/tree/main/Hex.

Selected calculations in `src/Hex.Plugin/Native/HexMovement.cs` adapt aedenthorn/ValheimMods at commit `83690e8ef9a37c4694604416667d252b4ff5f645`: Regeneration/Regeneration.cs (stamina consumption multiplier) and JumpRunDodgeSneakWalk/BepInExPlugin.cs (jog/run factors, jump/swim multipliers, airborne jump allowance and fall-altitude calculation). This is attribution for reference portions, not Meadworks product authorship. The pin's root public-domain dedication is retained byte-for-byte in THIRD_PARTY_NOTICES/aedenthorn-Public-Domain.txt. Neither selected subproject has a separate license or labeled external-source exception in the audited pin.

Original adaptations add actual local ownership, server policy evaluation on each hook, personal preferences, conditional temporary-field restoration, stamina availability at an empty bar, original owner-body moon gravity and native refusal cleanup. No global Character.Awake mutation, sneak/turn/dodge animation override or complete upstream plugin lifecycle is adopted.

`src/Hex.Plugin/Native/HexDurability.cs` additionally adapts only Durability/Durability.cs BlockAttack_Patch's snapshot and reduction-only delta (lines 183-203) from that same pin. Its subproject also has no separate license or labeled external-source exception. The adaptation retains the exact native inventory item, covers weapon blockers as well as shields, and adds original scoped native attack/tool protection and timed-wear prevention. It does not copy global ItemDrop.Awake changes, the broad armor rewrite or the IL instruction-pattern transpiler.

Crucible, Jotunn, BepInEx, Unity and Valheim assemblies are external runtime/build references, never embedded. The publicizer NuGet dependency is MIT; its retained notice is included. No game code or game assets are included. Native API inspection does not transfer the game's copyright. Valheim_Admin_Tool and AchievementSync are design behavior references only, with no source/DLL adoption; their remaining features are not represented as implemented.

`Native/HexEitr.cs` is an original implementation of the approved unlimited-eitr behavior using current native API inspection. It does not adopt EitrRegenRate's field multiplier: regeneration is a different behavior. It answers the native use/availability gates and removes positive finite consumption without changing food, maximum, reserve or resource serialization. VAT remains a behavior-only description for this feature, with no code or assembly access.

`Native/HexCarry.cs` is an original implementation of the approved no-carry-limit/custom-capacity behavior using the current native capacity query and inventory readout. It never changes the stored base weight and retains normal equipment/mod contributions when neutral. VAT remains a behavior-only description. Mantle's own formatter updates are maintained in that separate repository with its existing licensed adoption provenance; no Mantle source is embedded into Hex.

`Integration/EdgeWear.cs` is an original optional adapter to Meadworks' own Edge. It uses the exact existing static void DrainItemDurability(Character, ItemData, float) method, discovered from the already loaded own product and verified by declaring type/signature. No Edge source is embedded, no external assembly is decompiled and no shared capability framework was added.

`Native/HexFood.cs` is an original semantic field-write adapter for the approved food-time pause, from native API/IL inspection outside the repository. It substitutes only the exact Player.Food.m_time write in Player.UpdateFood, checks one unambiguous store and preserves the native surrounding lifecycle. No native game code or broad reference UpdateStats implementation is included. VAT is a behavior-only description, with no source or assembly access.

`Native/HexDeath.cs` is an original narrow semantic-call adapter for the four independently gated death protections. The approved public-domain DeathTweaks project was inspected as inspiration, with courtesy credit to aedenthorn; its complete Player.OnDeath replacement is not copied or adopted. Native death, statistics, callbacks, saves and respawn remain intact. No copied game code is included. VAT remains behaviour only.

Launcher, injection, resource/configuration/terrain code, custom skins/textures and all source art are excluded.
