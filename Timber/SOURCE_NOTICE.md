The OpenKeep BuildCamera core (Copyright (C) 2026 Gerald Glasgow, GPL-3.0-or-later) is adopted from `ad278ecf323901c3645eb1f9f6fac6833a0f8cb1` at https://github.com/geraldjglasgow/ValheimMods. Sixteen native camera files are adapted under `src/Timber.Plugin/Camera`; source `CameraModule.cs`, `PickupPanel.cs` and `PickupPanelLook.cs` are excluded. The exact project license blob is retained in `THIRD_PARTY_NOTICES/OpenKeep-LICENSE.txt`, in addition to the full GPL text. Changes are identified in every adopted header: Timber namespace, C01 effective settings and C03 tracking, C05 messages, C07 input gating, product/headless/lifecycle gate, C09 camera-only coexistence, native ward access before pickup ownership, and owned light cleanup. Original integration helpers wrap these algorithms. No copied OpenKeep UI or broad framework is included. The original `CameraPickupHud` adapter presents the actual adopted pickup/CameraNeeds producer through Crucible.UI KitHudPanel and KitCanvas. It retains the reference one-second blocked notice behavior; source PickupPanel/PickupPanelLook construction and styling remain excluded. The OpenKeep Homestead `FirePlacement.cs` prefab-original capture/restore/live ghost mechanism is also adopted at the same GPL pin, under `src/Timber.Plugin/Flooring`. Original adapters select native Fireplace/Fire comfort pieces, extend the capture to all three agreed placement flags, preserve distinct later writes on restoration, bind C01/C03 configuration, provide C09 per-feature coexistence and own scene/teardown restoration. `FirePrefabs` and `FiresRuntime` are original integration files; upstream list parser/framework source is not copied. This adoption covers Fires On Floors, not a whole-flooring adoption. `FloorRoofTags.cs` is an original native-API implementation: floor usage flag classification, tracked leaky collider tags, cloned hierarchy baseline recovery and native cached-roof invalidation. Carturs_Flooring remains behavior only; none of its code is copied. The same adopted placement store is extended to native Smelter components, with an original current-owner eligibility branch over the existing selected support-wear kernel; `FloorRainWear.cs` holds only the native floor rain timer. These behaviors are not a Cartur code adoption. Carturs_Flooring source is unlicensed and was never read/copied. HoeRadius does not match the approved interaction and is not adopted. Valheim-owned API inspection informed the hooks and the inverse support-wear flag semantics; no decompiled game code is redistributed.

## Existing Meadworks player-lock reuse

Timber reuses expDARE's Kindle at commit `9420d1817c585492e36c5dd6c9e8a65cf231c4eb`: `src/Kindle.Core/Config/PlayerLocks.cs`, `src/Kindle.Plugin/Integration/KindleSyncReceipt.cs`, and the publish/read/authority/read-only pattern in `src/Kindle.Plugin/Config/KindleConfig.cs`. Timber substitutes its bound Local settings lookup, C01 hidden binding and product lifecycle. The exact connection receipt algorithm is unchanged except namespace/type and nullable annotations. This is reuse within ExtraPotions; product authorship remains expDARE. GPL-3.0-or-later applies.

The approved 100-metre camera reach correction is an original native integration over the adopted CameraReach scope. CameraRayPatches substitutes only the exact Physics.Raycast overload in Player.PieceRayTest, RemovePiece, CopyPiece and UpdateWearNTearHover; all other native checks remain. Those four sites and the untouched rebound/alternate hotbar loop were inspected from Valheim's own assembly, SHA256 25A0A107DCE4D834C44C2B72D0EAFD5CB7793933BDA81816ACCFA1EA9543DACE. No third-party assembly or game method body is copied into Timber.


Touching-piece Area Repair adapts OpenKeep Homestead RepairPatch, RepairArea, RepairChecks, RepairSettings and RepairNeighbours at GPL-3.0-or-later pin 3bb778330f23645ccddb42fbc0c6ffab72c842b6. Existing OpenKeep copyright/license notices are retained. Timber adds default-off C01 configuration, captured center/original-run gates, bounded collision queries/candidates and per-call scratch cleanup. Native repair costs and owner RPC remain unchanged; no decompiled game implementation is copied.
