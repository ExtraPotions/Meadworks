## Corresponding source for Wayfarer 0.5.16

This source archive contains the source snapshot for the paired runtime assemblies. Corresponding source for this build is identified by SOURCE-SNAPSHOT.json and BUILD-RECIPES/code-release-0.5.16/BUILD.json. Historical compiler-reference source and DLL supplements remain part of the release source inventory. No broader native acceptance is asserted.
